
# GBA Vampire Survivors Prototype

Proyecto inicial estilo Vampire Survivors para Game Boy Advance.

## Contenido

- Movimiento del personaje con cruceta
- Enemigo básico que sigue al jugador
- Sprites simples incluidos
- Build con Docker + devkitARM

## Controles

- D-Pad: mover personaje

## Compilar

```bash
chmod +x build.sh
./build.sh
```

El resultado será:

```bash
gba_vampire_survivors.gba
```
