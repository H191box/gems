CONTROLES

MENU
-----
UP / DOWN -> Cambiar opcion
A -> Entrar

FARMEO
-------
B -> Nueva mutacion de plasma
A -> Guardar plasma
START -> Volver al menu

GALERIA
--------
START -> Volver al menu

ESTRUCTURA
----------
main.c      -> Estados del juego
menu.c      -> UI del menu
plasma.c    -> Renderizado y paleta
save.c      -> SRAM y datos guardados
